# ☁️ Azure Cloud-Based Web Application Infrastructure


Designed and implemented a scalable and secure 3-tier web application architecture on Microsoft Azure, consisting of frontend, backend, and database layers.  Built a Virtual Network (VNet) with segmented public and private subnets to ensure proper isolation between application tiers. Configured Network Security Groups (NSGs) to control inbound and outbound traffic, restricting access based on ports and service requirements.  Deployed the backend application on a Linux-based Azure Virtual Machine using Node.js, and integrated it with Azure SQL Database for structured and secure data storage.  Implemented Azure Application Gateway for load balancing, enabling high availability and efficient traffic distribution across the application.  Configured Azure Monitor to track performance metrics, logs, and system health, and used it to identify and troubleshoot real-world issues such as connectivity failures, NSG misconfigurations, and service downtime.  Focused on building a production-like cloud environment by applying core cloud concepts including network isolation, secure access, scalability, and monitoring.
